# 退休試算工具 v1.0 測試案例集\n\n## 0. 測試前提\n\n**基準組合（BASE）**，各案例僅列出「相對 BASE 的覆寫欄位」：\n\n| 參數 | 值 |\n|---|---|\n| `A_c` / `A_r` / `A_d` | 30 / 60 / 85 |\n| 本金 / 月存 | 1,000,000 / 10,000 |\n| `r` / `r_p` / `i` | 6% / 3% / 2% |\n| 月支出 / 固定年支出 | 50,000 / 0 |\n| 大筆支出金額 / `A_e` | 0 / 無 |\n| 勞保月領 / 請領年齡 | 0 / 65 |\n| 勞退月領 / 請領年齡 | 0 / 65 |\n\n**判定容差假設（規格未定義，測試側自訂）**：金額比對容差 ±1 元或相對誤差 1e-6，取大者。\n\n---\n\n## 0.1 規格缺口清單（阻斷判定用）\n\n以下項目規格書未規範，因此**無法產生唯一正確答案**。凡標記 ⚠ 的案例，其「預期輸出」只寫到規格可判定的部分，其餘僅要求「記錄實際行為並回送規格確認」，不得由測試側自行認定通過。\n\n| 缺口 ID | 影響條款 | 內容 |\n|---|---|---|\n| G-01 | PRD-01 | 月存款是**期初**或**期末**投入未定義 |\n| G-02 | PRD-01 | 累積期月數是否等於 `(A_r − A_c) × 12` 未明文定義 |\n| G-03 | PRD-02 | 折現所用**折現率**未指定（`r_p`？`r`？實質利率？） |\n| G-04 | PRD-03 | 餘額為負時是否仍套用 `r_p` 未定義 |\n| G-05 | PRD-03 | 軌跡回傳的是「期初扣款後」或「年末結餘」未定義 |\n| G-06 | PRD-05 | 大筆支出是否隨通膨調整、通膨基準年為何未定義 |\n| G-07 | PRD-05 | `A_e > A_d` 未規範（條文僅有下界 `A_r ≤ A_e`） |\n| G-08 | PRD-06/07/10 | 收入通膨指數的**基準年**未定義（`A_c`？請領年？`A_r`？） |\n| G-09 | PRD-01/02 | 累積結果與目標金額的「缺口」如何計算未定義 |\n| G-10 | 全域 | 四捨五入位數、數值上界、幣別精度未定義 |\n\n---\n\n## 1.
