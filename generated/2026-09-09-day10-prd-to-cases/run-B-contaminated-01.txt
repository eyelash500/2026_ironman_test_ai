## 自動化標記說明

| 標記 | 說明 | 適用情境 |
|------|------|---------|
| **Auto** | 可完全自動化執行 | 計算結果數值比對、校驗錯誤回傳、軌跡陣列逐期比對 |
| **Semi** | 需人工觸發或準備，部分步驟可自動化驗證 | 介面標註文字確認、欄位保留狀態確認 |
| **Manual** | 需完全人工操作與判斷 | （本輪無） |

| 前綴 | 模組 / 類別 | 對應條款 |

## 通用基準輸入（Baseline）

除案例另行指定外，一律採用以下輸入，未提及的金額欄位皆為 0：

`A_c = 35`、`A_r = 65`、`A_d = 85`、`r = 0`、`r_p = 0`、`i = 0`、本金 = 0、月存 = 0、月支出 = 0、固定年支出 = 0、大筆支出 = 0、勞保月領 = 0、勞退月領 = 0。
