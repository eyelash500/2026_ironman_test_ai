## 基準情境 B（Baseline）

以下所有案例除特別註明覆寫的欄位外，其餘參數皆沿用本組基準值。案例的「輸入參數」欄僅列出對基準的差異。

| 參數 | 符號 | 基準值 |
|------|------|--------|
| 現齡 | `A_c` | 35 |
| 退休年齡 | `A_r` | 65 |
| 預期壽命 | `A_d` | 85 |
| 退休前報酬率 | `r` | 6% |
| 退休後報酬率 | `r_p` | 3% |
| 通膨率 | `i` | 2% |
| 期初本金 | `P` | 1,000,000 |
| 月存金額 | `M` | 10,000 |
| 月支出 | `E` | 50,000（`A_c` 基準） |
| 固定年支出 | `F` | 100,000（`A_c` 基準） |
| 勞保年金 | — | 20,000／月，即 240,000／年（`A_c` 基準） |
| 勞退月領 | — | 10,000／月，即 120,000／年（`A_c` 基準） |
| 請領年齡 | — | 65 ⚠️（規格未定義，暫以輸入參數處理，見 §9） |
| 大筆支出年齡 | `A_e` | 70 |
| 大筆支出金額 | `X` | 1,000,000 |
| 軌跡起始資產 | — | 5,000,000（`WD` 系列直接指定，避免與 `AC` 系列耦合） |

年支出基準（`i = 0` 時）：`E × 12 + F = 700,000`
折現期數（PRD-02）：`A_d − A_r + 1 = 21`

## 自動化標記說明

| 標記 | 說明 | 適用情境 |
|------|------|---------|
| **Auto** | 可完全自動化執行 | 純計算函式驗證、數值比對、校驗錯誤回傳檢查 |
| **Semi** | 需人工觸發或準備，部分步驟可自動化驗證 | 表單層攔截行為、需人工設定輸入組合後自動驗算 |
| **Manual** | 需完全人工操作與判斷 | 介面標註文字、視覺確認 |

## 1. 累積期增值（AC）

驗證本金與月存是否統一採名目月利率 `r/12` 月複利，以及 `r = 0` 的線性退化。

| Case ID | 宣稱覆蓋條款 | 測試情境 | 前置條件 | 輸入參數 | 預期輸出 | 優先級 | 自動化 |
|---------|-------------|---------|---------|---------|---------|--------|--------|
| AC-001 | PRD-01（邊界處置） | `r = 0` 退化為線性累加 | 輸入通過 PRD-04 校驗 | `r = 0`，`P = 1,000,000`，`M = 10,000`，累積 360 個月 | 累積期末金額 = `4,600,000`（= `P + M × 360`），不得出現任何複利增值 | P0 | Auto |
| AC-002 | PRD-01 | 僅本金增值，驗證利率基準為名目月利率 | 同上 | `M = 0`，`P = 1,000,000`，`r = 6%` | 累積期末金額 = `1,000,000 × (1 + 0.06/12)^360` = `6,022,575.21`（容許誤差 ±0.01）；**不得**為 `5,743,491.17`（誤用實質年利率 `(1+r)^30`） | P0 | Auto |
| AC-003 | PRD-01 | 僅月存增值，驗證月存亦採 `r/12` 月複利 | 同上 | `P = 0`，`M = 10,000`，`r = 6%` | 累積期末金額 = `10,045,150.42`（期末年金）或 `10,095,376.18`（期初年金），視實作定義；兩者皆須以 `r/12` 為單期利率 ⚠️ 期初／期末未於規格定義，見 §9 | P0 | Auto |
| AC-004 | PRD-01 | 本金與月存共用同一利率基準 | 同上 | `P = 1,000,000`，`M = 10,000`，`r = 6%` | 累積期末金額 = AC-002 結果 + AC-003 結果（線性可加），差異須為 0；若不可加即代表兩者採用不同利率基準 | P0 | Auto |
| AC-005 | PRD-01（邊界處置） | `r = 0` 且 `M = 0` | 同上 | `r = 0`，`M = 0`，`P = 1,000,000` | 累積期末金額 = `1,000,000` | P1 | Auto |
| AC-006 | PRD-01 | 累積期數 = `(A_r − A_c) × 12` | 同上 | `A_c = 35`，`A_r = 36`，`r = 0`，`P = 0`，`M = 10,000` | 累積期末金額 = `120,000`（12 期）；不得為 `110,000` 或 `130,000` | P1 | Auto |
