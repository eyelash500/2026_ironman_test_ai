## 自動化標記說明

| 標記 | 說明 | 適用情境 |
|------|------|---------|
| **Auto** | 可完全自動化執行 | 計算引擎單元／整合測試、輸入校驗回傳值比對 |
| **Semi** | 需人工觸發或準備，部分步驟可自動化驗證 | 介面標註文字確認 + 計算結果自動比對 |
| **Manual** | 需完全人工操作與判斷 | 介面說明文字、視覺確認 |

## 基準輸入組（BASE）

以下所有案例的「輸入參數」欄僅列出**與 BASE 不同的覆寫值**，未列出者一律沿用 BASE。

| 參數 | BASE 值 |
|------|--------|
| `A_c` 現齡 | 40 |
| `A_r` 退休年齡 | 65 |
| `A_d` 預期壽命 | 85 |
| 本金 | 0 |
| 月存 | 0 |
| 月支出 | 0 |
| 固定年支出 | 0 |
| 大筆支出金額 / `A_e` | 0 / 無 |
| 勞保月領 / 請領年齡 | 0 / 65 |
| 勞退月領 / 請領年齡 | 0 / 65 |
| `r` 退休前報酬率 | 0% |
| `r_p` 退休後報酬率 | 0% |
| `i` 通膨率 | 0% |

金額單位為 TWD，年齡單位為歲。所有金額比對允許 ±1 元捨入誤差，比率比對允許 1e-9 誤差。
