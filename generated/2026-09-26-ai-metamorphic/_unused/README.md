## `classify.py`

143 條關係的逐條人工分類（對帳／縮放／單調／不變／退化／結構／校驗），
附 3 組 KAT 確認標籤與實際函式一一對上。

**為什麼不用**：分布表撐不住。提示詞為了說明蛻變測試的形狀，舉了 `sort()` 的例子：

    把 xs 的順序打亂 → 結果必須完全相同      ← 示範了「不變」
    多加一個元素 → 長度必須剛好多 1          ← 示範了「結構」

而產出裡「不變」63 條（最大宗）、「結構」6 條，其中「打亂大筆支出順序」4 份、
「壽命 +N → 軌跡長度 +N」6 條，幾乎是那兩行的逐字翻譯。
**分布有一部分是我自己的例子回音**，不能當成 AI 的傾向。

這件事沒有乾淨解——任何例子都在示範某種形狀，換一個例子只是換一種污染。
所以處置是「不宣稱分布」，而不是重跑。不宣稱分布，這份分類就沒有用武之地。

**裡面有一條已撤回的判定**：`定義性恆等` 那一欄（5 條）標錯了。
`Δ缺口 == −Δ資產` 看起來是同義反覆，但 `retirement_gap` 在 `calc_fixed.py` 153 行
就是 `target_fund - projected_savings`，所以：

    Δ缺口 ≡ Δ目標金額 − Δ資產            （定義，恆成立）
    斷言 Δ缺口 == −Δ資產  ⟺  Δ目標金額 == 0

那五條只動期初資金，所以它們斷言的是**正交性**，一條真關係，不是恆真命題。
**判錯的原因是看形狀沒做代數**——與 Day 25 把「殺 0 個」讀成「廢話」同一種錯。
若日後要復用這份分類，那一欄必須先修掉。
