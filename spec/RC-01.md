# RC-01：退休當年與壽命當年

- **性質**：沉默決定
- **程式碼座標**：`sut/進階退休規劃試算.html` 306、349 行

## 現有實作

```javascript
for (let i = 1; i <= retirementYears; i++) { const age = retirementAge + i; ... }
```

## 隱含假設

第一個被計算的年份是 A_r + 1（退休當年不計支出），最後一年是 A_d（壽命當年計入）。
目標金額與提領期兩條路徑採同一組索引。

## 待裁決

- A. 維持現況：退休當年不計支出，共 A_d − A_r 年
- B. 退休當年即為首年：共 A_d − A_r + 1 年
- C. 兩端都不計：共 A_d − A_r − 1 年

## 裁決

**改**：退休當年（`A_r`）即為提領首年，共 `A_d − A_r + 1` 年。

- **對應條款**：PRD-02
- **裁決者**：人（閘門 1）
- **裁決日**：2026-09-09（Day 9）

### 理由

原以為只是索引寫法，實測發現它讓目標金額差 194,977 元（基準情境）——
Day 4 推導的 (1+r) 只解釋了偏差的三分之二，剩下三分之一來自這個 `i = 1`。
