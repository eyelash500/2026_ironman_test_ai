# RC-03：名目月利率

- **性質**：歧義
- **程式碼座標**：`sut/進階退休規劃試算.html` 297 行

## 現有實作

```javascript
const monthlyPreReturn = preRetirementReturn / 12;
```

## 隱含假設

月利率取 r/12（名目），而非 (1+r)^(1/12) − 1（有效）。
僅用於月存終值（298 行）；本金（296 行）走年複利。

## 待裁決

- A. 維持 r/12（名目）
- B. 改為有效月利率 (1+r)^(1/12) − 1
- C. 月存改折算為年金、按年複利

## 裁決

**維持**：續用名目月利率 `r/12`。

- **對應條款**：PRD-01
- **裁決者**：人（閘門 1）
- **裁決日**：2026-09-09（Day 9）

### 理由

實查六個試算器：中信退休試算、中信投資試算、富邦、國泰嚮退 Easy 皆用 r/12；
國泰試算小幫手用年複利；YP-Finance 用有效月利率。四比二，維持相容性。
代價：基準情境下月存段多算 631,816 元。
