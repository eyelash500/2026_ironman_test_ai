# RC-04：同帳戶兩種複利頻率

- **性質**：歧義
- **程式碼座標**：`sut/進階退休規劃試算.html` 296 vs 298 行

## 現有實作

```javascript
const fvCurrentSavings = currentSavings * Math.pow(1 + preRetirementReturn, workingYears);      // 年複利
const fvMonthlyInvestments = monthlyInvestment * (Math.pow(1 + monthlyPreReturn, workingYears * 12) - 1) / monthlyPreReturn;  // 月複利
```

## 隱含假設

同一個帳戶、同一個報酬率，本金按年複利、月存按月複利。相鄰兩行，兩種頻率。

## 待裁決

- A. 統一為月複利 r/12
- B. 統一為年複利
- C. 統一為有效月利率

## 裁決

**改**：本金與月存統一為 `r/12` 月複利。

- **對應條款**：PRD-01
- **裁決者**：人（閘門 1）
- **裁決日**：2026-09-09（Day 9）

### 理由

原擬與 RC-03 綁在一起維持現況，查證後改判：六個試算器中**沒有任何一個**
混用兩種頻率，每一家內部都一致。「維持現況」在這一條沒有市場依據。
代價：本金部分 +6.59%，累積期合計 +1.55%。
