# RC-06：大筆支出沒有上界

- **性質**：已知缺陷 C
- **程式碼座標**：`sut/進階退休規劃試算.html` 329 行

## 現有實作

```javascript
if (age >= retirementAge) { ... }
```

## 隱含假設

折現迴圈只檢查下界，沒有壽命上限。超過壽命的支出（如 95 歲）會計入目標金額，
卻不出現在圖表上。

## 待裁決

- A. 補上上界：僅 A_r ≤ A_e ≤ A_d 計入
- B. 全部計入，並延長圖表至最後一筆支出
- C. 維持現況（不可行：目標與圖表不一致）

## 裁決

**改**：補上壽命上界，僅 `A_r ≤ A_e ≤ A_d` 計入。

- **對應條款**：PRD-05
- **裁決者**：人（閘門 1）
- **裁決日**：2026-09-09（Day 9）

### 理由

缺席規則，無取捨可言。超出壽命者兩條路徑一律排除，介面標註已忽略。
