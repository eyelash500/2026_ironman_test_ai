# RC-10：輸入防呆

- **性質**：已知缺陷 D
- **程式碼座標**：`sut/進階退休規劃試算.html` 215、275–290 行

## 現有實作

```javascript
const parseNumber = (str) => parseFloat(String(str).replace(/,/g, '')) || 0;   // 215
const currentAge = parseInt(document.getElementById('currentAge').value);      // 275
```

## 隱含假設

金額欄位經 parseNumber，空值與非數字靜默補 0；
年齡欄位走 parseInt，取得 NaN 後所有比較恆為 false，整筆輸入被無聲丟棄。
